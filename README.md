# FreshNest

FreshNest is a zero-dependency demo storefront built with vanilla HTML, CSS, and JavaScript.

Open `frontend/index.html` in a browser (or serve the repository as a static site) to try the product filters, custom cuts, basket, demo delivery areas, and order journey. Basket and delivery selections are saved in browser `localStorage`; no payment or FreshNest backend request is made. Product photos load from Unsplash.
